❓ Aide à l'installation

📱 Comment installer ?

Installation en 30 secondes.

🤖 Android (Chrome)

  1. Ouvrez Chrome
  2. Allez sur le lien
  3. Appuyez sur 3 points ⋮
  4. Cliquez sur "Installer"
  5. ✅ L'icône apparaît !

iPhone (Safari)

  1. Ouvrez Safari
  2. Allez sur le lien
  3. Appuyez sur Partager
  4. Cliquez sur "Sur l'écran d'accueil"

🔐 Demander un accès

  1. Ouvrez l'application
  2. Cliquez sur "📩 Demander un accès"
  3. Créez vos identifiants
  4. Kevin validera votre demande

🔄 Mises à jour

L'application se met à jour automatiquement. Vous avez toujours la dernière version.
